### 课程介绍

该课程包含AI大模型应用开发基础、AI大模型应用核心开发技术、Coze和Dify工作原理和应用技术、机器学习框架与模型训练、AI大模型应用综合开发实战等方面内容。通过此课程，能让你学习到大模型能做什么、大模型落地现状、大模型的通俗原理、大模型应用架构等知识内容，让AI成为你学习中的老师、工作中的助手、休闲时的朋友，做一名AIGC浪潮中顶尖的超级个体。如果你懂业务或者懂编程，通过此课程可以拥有AI的加持；如果你既懂业务又懂编程，通过此课程可以提升为一名AI全栈工程师。无论是在校大学生还是职场人士，都适用于学习本课程。

### 课程大纲

1）AI大模型基本原理

2）Python基础编程

3）Prompt工程：设计与优化

4）GPU与CPU：计算硬件和大模型训练

5）API基础与通过API调用大模型

6）Cursor编程-从入门到精通

7）Embeddings和向量数据库

8）RAG技术与应用

9）RAG高级技术与最佳实践

10）LlamaIndex：知识管理与信息检索应用

11）LangChain：多任务应用开发

12）Function Calling与跨模型协作

13）Agent智能体系统的设计与应用

14）AutoGPT原理和实现

15）Fine-tuning技术与大模型优化

16）Coze工作原理与应用实例

17）Coze应用、插件与SDK开发

18）Dify本地化部署和应用

19）PyTorch基础与应用

20）PyTorch进阶：复杂网络模型搭建、迁移及部署

21）TensorFlow及其应用
